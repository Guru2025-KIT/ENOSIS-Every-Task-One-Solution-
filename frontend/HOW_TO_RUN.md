# How to Run ENOSIS (Phase 1–9 build)

This zip contains **only** the Dart application code (`lib/`), assets, docs, and
`pubspec.yaml` — not the Android/iOS/web platform folders. Those are generated by
the `flutter create` command itself and depend on the exact Flutter/Android SDK
versions on *your* machine, so it's safer for you to generate them locally rather
than have me hand you gradle files that might not match your SDK.

## Prerequisite
`flutter doctor -v` should be clean (from the setup guide). If it isn't, fix that first.

## Steps

### 1. Create an empty Flutter project shell
```bash
mkdir enosis
cd enosis
flutter create .
```
This generates `android/`, `ios/`, `web/`, `linux/`, `macos/`, `windows/`, a default
`lib/main.dart`, and a default `pubspec.yaml` — all matched to your installed SDK.

### 2. Unzip the file I gave you
Unzip `enosis_flutter_app.zip` anywhere on your machine.

### 3. Copy these into your new `enosis/` project, overwriting when prompted
- `lib/` → replaces the default `lib/` folder entirely
- `pubspec.yaml` → replaces the default one (adds our app name + assets config)
- `assets/` → new folder, add alongside `lib/`
- `docs/` → new folder, add alongside `lib/`
- `HOW_TO_RUN.md` → optional, just for your reference

Your `enosis/` folder should now look like:
```
enosis/
  android/        <- generated by flutter create, untouched
  ios/             <- generated by flutter create, untouched
  web/             <- generated by flutter create, untouched
  lib/             <- ours
  assets/          <- ours
  docs/            <- ours
  pubspec.yaml     <- ours
```

### 4. Add the real logo
Save the ENOSIS logo PNG as exactly `assets/branding/enosis_logo.png`
(see `assets/branding/README_ADD_LOGO_HERE.txt`). The app runs fine even without
it — it just shows a fallback icon instead — but do this before your first real run.

### 5. Install dependencies
```bash
flutter pub get
```

### 6. Run it
Start your emulator (Android Studio → Virtual Device Manager) or plug in your
phone with USB debugging on, then:
```bash
flutter run
```

### 7. What you should see
Splash screen with the ENOSIS logo → Login screen → (type anything, tap Login) →
Dashboard with the 5-tab bottom nav (Home / My Day / Assistant / Alerts / Profile).

## If something breaks
- `flutter pub get` fails → check your internet connection; it needs to reach pub.dev.
- Red screen mentioning a missing asset → confirm `assets/branding/enosis_logo.png`
  exists at that exact path, and that `pubspec.yaml`'s `assets:` section lists
  `assets/branding/`.
- Any other red error screen → copy just the **first few lines** of the error
  (not the whole stack trace) and send it to me. Per our debugging rule, we
  diagnose it together — I won't just hand you a blind rewrite.
